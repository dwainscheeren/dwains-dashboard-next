# User Permissions

Dwains Dashboard Next can restrict behavior for non-admin users.

## Home Assistant Sidebar

You can hide the Home Assistant sidebar for non-admin users. Their own Home Assistant profile remains accessible.

## Dashboard Editing

You can prevent non-admin users from opening Dwains Dashboard settings or editing dashboard content.

## Defaults

By default, non-admin users can see the Home Assistant sidebar and can use normal dashboard controls. Restrictions are opt-in and can be changed in Dashboard settings.
