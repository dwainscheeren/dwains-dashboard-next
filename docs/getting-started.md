# Getting Started

Dwains Dashboard Next uses your Home Assistant setup as the source. The better your areas, devices and entities are organized in Home Assistant, the better the dashboard will look.

## Recommended Home Assistant Setup

1. Put devices in the correct areas.
2. Put areas on the correct floors.
3. Give areas clear icons.
4. Hide or disable entities you do not want to use.
5. Add useful favorites in Home Assistant.

## First Dashboard Check

After creating the dashboard:

1. Open the home page.
2. Check if your areas are listed correctly.
3. Open an area and check if lights, switches, covers and sensors are grouped correctly.
4. Open the Devices page and verify the device groups.
5. Open Dashboard settings and adjust visibility, order and permissions.

## Important Behavior

- Entities without an area are hidden by default.
- Unavailable entities are hidden by default in device views unless enabled in settings.
- Camera cards only show available camera entities.
- The home page order can be changed in Dashboard settings.
